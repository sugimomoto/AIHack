## ★ 今回の方針転換

**「取り決め」画面は、公正証書に入れる内容を管理する場所です。そこに AI は触りません。本人が入力します。**

| | 誰が作るか | AI の関与 | 公正証書 |
| --- | --- | --- | --- |
| **取り決め** | **本人が入力する** | **無い** | **載る** |
| 相談（対話） | AI が仲介する | 受け止めと取次ぎ | 載らない |

**相談は残ります。取次ぎも、臨時費用の相談もそのままです。ただし相談は取り決めを動かしません。**

**相談（対話）の画面は変更していません。** 第1弾・第2弾のまま使ってください。

### 合意の作られ方

**片方が仮案を作り、もう片方が了承します。** 双方が独立に記入して一致を待つ形ではありません（そんな一致は起きないため）。

```
本人が入力 → 下書き（相手に見えない）→ お渡しする → 相手が了承 → 合意済
                    ↑                      ↓
                    └── 取り下げる ────────┘
                                           ↓
                                    別の案（例外的な経路）
```

## A-2. 論点ごとの画面 — 6つの状態

| 状態 | 地 | 上部の帯 | 主な操作 |
| --- | --- | --- | --- |
| **未入力** | `bg` | なし | 入力フォーム |
| **下書き** | **`surface-2`** | **鍵つきの帯** | 直す／お相手に見ていただく |
| **お相手のご返事待ち** | `bg` | なし | 取り下げる |
| **お相手から別の案** | `bg` | なし | 了承する／また別の案 |
| **合意済** | `bg` | なし | 変更を申し出る（K-6） |
| **取り下げました** | **`surface-2`** | **帯の文言が違う** | 直す／お相手に見ていただく |

### ★ S-1. 下書き — 地の色ごと閉じる

**トグルや鍵アイコン1つで示しません。画面全体を閉じます。**

```
画面の地      bg (#FDF8EF) → surface-2 (#F7EFE1)
上部の帯      surface / #DCC7A6 の1px / 角丸16px / margin: 0 16px 14px
              鍵アイコン14px（線 ai-text）＋「まだお相手には見えていません」12.5px
```

準備モード（第2弾 B）と同じ手法です。**渡した瞬間に、地と帯の2点が同時に変わります。** 部品を1つ足すより、状態の差が強く出ます。

**★ 実装ルール**

- 破線の注記「何度でも書き直せます。お渡しになるまで、お相手には何も伝わりません。」
  → **下書きは考えるための場所です。見えていると思い込むと、書けなくなります**
- 「直す」「このことを相談する」を同じ重さで並べる
- **「お相手に見ていただく」は一方向のボタン。トグルにしません**

> **★ ON/OFF のスイッチにすると、取り消せるように見えます。**
> 操作の見た目が、実際にできることより多くを約束してしまう。
> 取り下げは、渡したあとの画面にある**別の操作**です。往復する一つのスイッチには見せません。

### ★ S-1b. 渡す前の確認シート

押し間違いを防ぐ一段ですが、**重々しくしません。** 警告色も感嘆符も赤も使わず、確認は**内容の再掲**が主です。何が渡るのかを、渡る形のまま見せます。

```
［カピバラ28px］この内容を、お相手にお見せします。

［surface のカード］月額 / お支払いの日 / いつまで を再掲

［bubble-ai の地 + #DCC7A6 の1px］
  お渡ししたあとで取り下げることもできますが、
  一度ご覧になったことは取り消せません。      ← 太字

［お見せする］     agree の枠 + agree-bg
  まだ渡さない     枠なしのテキスト
```

**★ 「取り消せません」はこのシートの中に置いてください。** ボタンの下に小さく書いても、押す前には読まれません。

「まだ渡さない」は枠なし。**可逆な操作なので、重さを揃える必要がありません**（不可逆な選択肢どうしとは扱いが違います）。

### S-2. お渡ししたあと

- 地が `bg` に戻り、鍵の帯が消える
- 「8月13日にお渡ししました。」
- `surface-2` のカード:「お相手のご返事をお待ちしています」＋「**ご覧になったかどうかは、こちらでは分かりません。お急ぎいただくご連絡はしません。期限もありません。**」
- 破線の注記:「**お渡ししているあいだは、直せません。直したいときは、いったん取り下げてください。**」
- 最下部に「このことを相談する」「取り下げる」（**同じ枠。取り消しの操作を目立たせない**）

**★ 既読は持ちません**（第1弾の規律）。

### ★ S-5. 取り下げたあと

**地も操作も S-1 の下書きに戻りますが、帯の文言だけが違います。**

```
帯: 「下書きに戻りました。お相手には、取り下げられたことが見えています」

破線の注記:
  書き直して、もう一度お渡しになれます。
  ご覧になった内容は、お相手の記憶からは消せません。
```

**★ S-1b で約束したことを、ここでも同じ言葉で書いてください。** ここで黙ると、あの警告が形式だったことになります。

## ★ A-2. 了承する側（S-3）

**了承が自然な行動に見えること。ただし押させないこと**（合意は取り消せません）。

### 構成

1. **案は封書カードの形で置く**（第1弾③と同じ）
   - ヘッダ帯：`envelope-head` の地、下辺**破線**、封筒アイコン＋「**お相手が作られた案**」`agree-text`、右端に日付
   - 本文：定義リスト（月額 17px / お支払いの日 / いつまで）
   - **相手が作ったものだと、読む前に分かります**

2. **算定表の帯**（養育費のみ）— 案の値を目盛として重ねる
   - **第三者の範囲の中にあることが見えれば、了承の判断材料になります**
   - **範囲外でも警告は出しません**

3. 破線の注記「**いま決めなくてかまいません。ご返事があるまで、この案は残ります。**」

4. 選択肢（**枠線・面積・文字サイズをすべて同一**）
   - この内容で了承する
   - 別の案を出す
   - このことを相談する（枠なしのテキスト）

**★ 「了承する」を強調しません。** 1番目に置くことで最も自然な行動ではありますが、色や太さで押させることはしません。

### S-3b. 了承の確認

**S-1b と同じ構造の確認シートです。渡すときと了承するときで、同じ作法にしてください**（内容の再掲＋戻せない旨＋2択）。

```
［カピバラ28px］この内容で、取り決めになります。
［surface のカード］内容の再掲
［bubble-ai の地］取り決めになったあとで変えるには、お相手の同意が要ります。
                  公正証書の原案にも入ります。
［了承する］／ まだ決めない（枠なし）
```

## ★ S-4. お相手から別の案（例外的な経路）

**二つの金額を左右に並べません。並べた時点で交渉の卓になります。**

```
        お相手の案
          3万円
            │
━━━━━━━━━━━┿━━━━━━━━━━━━━━━━━━━━━  ← 算定表の帯（緑 = 月4万〜6万円）
                        │
                      5万円
                    はじめの案
```

**実装仕様**

```
帯:     高さ8px / 角丸4px / 地 border-subtle (#F1E9DC)
        範囲部分 #CFDEC9（agree の淡色）
目盛:   幅1px / 高さ12px / muted (#A99D8C)
ラベル: 11px text-sub（案の名前）/ 15.5px text（値）
```

**★ 守ること**

- **色も太さも同じ。** どちらかを強調しない
- **差額を計算しない。** 「2万円の開き」と書けば、それが争点として立ちます
- ラベルは「あなた／お相手」ではなく **「はじめの案／お相手の案」**
  → 仮案モデルでは案に時間の順序があります。**人ではなく案を主語にすると、対立の構図が薄くなります**
- 破線の注記「**どちらかが正しい、というものではありません。事情が違えば、見ているものも違います。**」

### 数量でない論点（面会交流など）

帯が引けないので、**合っている項目を先に、多く見せます。**

```
［カピバラ］5つのうち、3つは同じでした。

  回数     月1回        同じ  ← agree-text
  第何週   第2週        同じ
  時間     10時〜17時   同じ
  曜日     まだ揃っていません
             お相手   日曜日
             ご自身   土曜日     ← 同じ書式・同じ文字サイズ。左右でなく上下
  受け渡し まだ揃っていません
             ...

揃っていない2つだけ、お話しになれば足ります。   ← 残りの作業量を示す
```

## A-1. 一覧

4つの論点（**養育費・面会交流・財産分与・年金分割**）に、状態を1行ずつ。

```
養育費        まだ入力されていません
面会交流      下書きです（お相手には見えていません）   ← 地が surface-2 / 鍵アイコン
財産分与      お相手のご返事をお待ちしています
年金分割      合意できています                        ← agree-text
```

**★ 実装ルール**

- **数字を出しません**（1/4、○% などの進捗表示を作らない）
- チップも進捗バーも持たない。**状態は1行の文**
- **下書きの行だけ、地が `surface-2` に沈み、鍵アイコンが付く** — 一覧でも詳細と同じ手法で閉じていることを示す
- 見出しの下に「**順番はありません。**」、下部に破線で「**ひとつ合意できれば、それだけで書面にできます。全部が揃うのを待つ必要はありません。**」
- 何も無いときは第1弾 L-2 の「全部を決める必要は、ありません。」を最上部に

### タブバーの変更

**4つ目が「これから」→「決まったこと」。アイコンもカレンダー→チェックに変えてください。** カレンダーのままだと予定表に見えます。

## 入力する項目

| 論点 | 項目 |
| --- | --- |
| **養育費** | 月額・支払日・いつまで |
| **面会交流** | 回数・曜日・第何週・時間・受け渡し場所 |
| **財産分与** | 一括で支払う／清算済み／別途協議する の3択。一括なら金額と期限 |
| **年金分割** | 分割する／しない。分割するなら按分割合（**0.5 か「別途協議」の2択のみ**） |

**★ 財産分与に内訳（不動産・預貯金・保険）は持ちません。** 内訳を持てば条項も内訳ごとに要ります。扱えないものを入口に出さないという規律です。

### ★ フォームを詰問にしない4つ

| | |
| --- | --- |
| **飛ばせることを、先に見せる** | 各カードの見出しの右に「**あとでも**」11.5px `text-sub` を常時置く。入力してから分かるのでは遅い |
| **必須の印を持たない** | アスタリスクも「必須」ラベルも使わない。**全項目が任意** |
| **進捗を出さない** | 1/4 も ○% も出さない |
| **空欄を欠落として描かない** | 未入力は**破線の下線**と「—」（`muted`）。赤も感嘆符も使わない |

**「下書きにする」ボタンは、何か書くまで淡いまま**（`text: muted`）。押せないのではなく、まだ押す段階でないという見え方です。

### 財産分与

**★ 「内訳を書いていただく必要はありません」を先に書いてください。** 不動産や預貯金を一つずつ問われるのではないと分かって、はじめて開けます。

3択のうち「一括で支払う」だけが金額欄を持ち、選ぶと枠が `agree` に変わって欄が現れます。**他の2つと面積を揃え、推奨には見せません。**

破線の注記「**『別途協議する』も、記録として残ります。決まっていないことを決まっていないまま書面にできます。**」← ここが逃げ道ではなく選択肢であることは、この論点では特に重要です。

### ★ 年金分割

**「按分割合」という語を、選択の前に出しません。**

```
［surface-2 のカード］
  結婚していたあいだに納めた厚生年金の記録を、
  おふたりで分けるかどうか、という話です。

  いま受け取っている額が動くわけではありません。   ← 誤解が最も多い点
  将来受け取る年金の計算に使う記録を、分けるということです。

どうされますか
  ［分ける］  記録を分けることに、おふたりで合意します
  ［分けない］それぞれの記録を、そのままにします

［分ける割合］「分ける」を選ぶと     ← 選ぶまで opacity .55
  半分ずつ（0.5）／ 別途協議する

［muted-bg のカード］
  お手続きは年金事務所でご確認ください。期限や必要な書類があるとされています。
  ここでの記録は、おふたりの合意を残すためのものです。
```

**★ 年金事務所の注記は恒久的な枠として組んでください。** 外す前提のレイアウトにしないこと。

## A-3. 途中で伺う（お子さん・同居・年収）

養育費の入力時、算定表に要る情報が無ければその場で伺います。

**3つを1枚に積み、いま答えるものだけを `agree` の枠で開きます。** 答え終わった項目は上に畳まれ（「伺いました」`agree-text`）、これからのものは `opacity: .55`。**残りが何問かが、常に見えている状態**です。

**★ 出口を2つ用意してください。**

- 「この質問を飛ばす」（次へ進む）
- 「目安は出さずに入力へ戻る」（**全部やめる**）

後者が無いと、入り込んだ人が抜けられません。

破線の注記「**目安が無くても、月額はお決めになれます。**」
**★ 「目安が出ないと決められません」とは書きません。** 実質的な強制になります。

年収は第2弾 C の帯の解をそのまま（変換の図は必須）。

## ★ 公正証書（P-1）— 今回は実装しない場所取り

**依頼書 §5.5 のとおり、置き場所だけです。** あとから足すと、取り決め画面を作り直すことになります。

### 一覧からの入口

**区切り線の下に、1行の入口だけ。**

```
──────────────────────────────
公正証書                          ▸
まだお預かりしていません
```

**★ 論点カードと同じ形にしないでください。5つ目の項目に見えます。**

### P-1 の中身

```
［surface のカード］
  まだお預かりしています                    ← 16px
  公証役場でお作りになったものを、ここに置いておけます。
  写真でも、PDFでもかまいません。
  ［選ぶ］

［surface-2 のカード］
  お預かりしたものが、いちばん確かなものになります
  アプリでお作りするのは原案です。食い違いがあったときは、
  お預かりした公正証書のほうが正しいものになります。

［破線］中身を読み取ることはしません。お預かりするだけです。

［muted-bg］本籍・ご住所・お名前が載っているものです。
           この端末と、お預かりする場所の両方で保護されます。
           お相手には見えません。

──────────────────────────────
アプリでお作りするもの
  ［原案を見る］合意できた内容だけが入ります

**★ 守ること**

- **食い違ったら、預かった公正証書が正。アプリ側は「原案」と書き続ける。** 画面の上下もその順に
- 本籍・住所・氏名が載るものです。**保護の説明に1枠取り、軽く扱う見た目にしない**

## B. オンボーディング（3枚）

| | 画面 | 中身 |
| --- | --- | --- |
| 1 | アプリの説明 | 「書いた言葉は、そのままお相手に届きません」 |
| 2 | メールの登録 | 第3弾 I-6 のまま。**飛ばせる** |
| 3 | お相手を招待しますか | いま渡す／あとにする |

**状況の確認（5択）は廃止。** 全員が入力から始まるので、分岐する意味がありません。同居・お子さん・年収は取り決め画面（A-3）へ移動します。

### B-1. アプリの説明

```
［カピバラ座り 76px］
書いた言葉は、そのまま
お相手には届きません。

［surface のカード・3行］
  思っていることは、そのまま書いていただけます。
  取り決めは、ご自身で書いて残します。          ← 今回の方針転換
  おふたりの記録が同じになったとき、合意になります。 ← 同上

おふたりが直接やりとりすることには、なりません。
```

**★ 2行目・3行目を最初に伝えておかないと、A-2 の画面が唐突になります。**

### ★ B-3. 招待を戻すにあたって

第3弾では「招待をオンボーディングから外す」と決めました。理由は「聞いた時点で、アプリが相手に伝える前提でいることが伝わる」。**今回それを戻すので、3つの歯止めを入れています。**

1. **関係の状態を一切聞かない** — 最下部に「ご関係の状態は、うかがいません。」と明記
2. **2つの選択肢を、枠線・面積・文字サイズまで揃える**
3. **「お渡しになるまで、お相手には何も届きません」を選択肢より先に置く**（`bubble-ai` の破線カード）

「あとにする」の説明は「**ひとりで書きはじめて、渡すかどうかはあとで決められます**」。待機ではなく通常の使い方だと示すためです。

## C. 決まったこと（旧「これから」）

**引き算だけです。新しい要素はありません。**

### 外すもの

| 外すもの | 理由 |
| --- | --- |
| 毎月の支払日・会う日 | 予定を管理しない |
| 履行の記録（支払いました／確認しました） | **手間で押されない。押されないと「確認できていません」と出て、実際は払っているのに疑いが立つ** |
| 逸脱の検知・先取特権の説明 | 上に伴い出番が消える |
| リマインド | **督促になる** |
| 「予定を思い出させる通知は、設定で切れます。」 | **リマインドをやめるので、できないことを書かない** |

> **記録率が低い台帳は、正しい信号より誤った信号を多く出します。**

### 残るもの

```
決まったこと
お話し合いで決まったことの控えです。

  8月22日
  送迎                        お約束として控えています
  
  9月3日
  14時　小学校　父母会         お約束として控えています

  今回だけ　曜日 日曜日 に変更
  面会交流
  ──────────────────
  取り決めそのものは変わっていません。

公正証書に入るのは「取り決め」のほうです。
