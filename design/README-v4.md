## 0. 今回お願いしたいこと

| | 画面 | 重さ |
| --- | --- | --- |
| **A** | **取り決め（一覧＋4論点の入力・編集）** | ★**最重要。ここが今回の中心です** |
| **B** | オンボーディング（**3枚に削る**） | 中 |
| **C** | 「決まったこと」（旧「これから」） | 小（**引き算だけ**） |

**相談（対話）の画面は変えません。**第1弾・第2弾のまま使います。

---

## 1. ★ なぜ作り直すのか

### 1.1 これまでの作り

**対話しているうちに取り決めができあがる**、という体験でした。

```
「養育費のことで相談したい」
  → AI が聞き取り
  → 金額・支払日を抽出
  → 取り決めができる
```

### 1.2 実測で起きたこと

| 起きたこと | 中身 |
| --- | --- |
| **進学費用の相談が、合意済みの養育費の月額を書き換えうる状態だった** | 別の話をしているのに、既にある取り決めが動く |
| **「スマホ代」が「コピー代」に化けた** | 抽出時の言い換えが、品目名まで変えていた |
| **はっきり書いた人ほど、伝わる中身が減っていた** | 原文と一致する部分を落とす検査が働き、要約が空になった |

歯止めは入れられます。しかし**歯止めが要ること自体が構造の問題**でした。

### 1.3 決めたこと

> **「取り決め」画面は、公正証書に入れる内容を管理する場所とする。**
> **そこに AI は触らない。本人が入力する。**

| | 誰が作るか | AI の関与 | 公正証書 |
| --- | --- | --- | --- |
| **取り決め** | **本人が入力する** | **無い** | **載る** |
| 相談（対話） | AI が仲介する | 受け止めと取次ぎ | 載らない |

**相談は残ります。**取次ぎも、臨時費用の相談も、そのままです。
ただし**相談は取り決めを動かしません。**

---

## 2. A. 取り決め（★最重要）

### 2.1 何が変わるか

| いま | これから |
| --- | --- |
| 対話の結果が並ぶ**表示だけの画面** | **入力する画面**。ここから作れる／直せる |
| 養育費・面会交流の2つ | **4つ**（＋財産分与・年金分割） |

### 2.2 A-1. 一覧

**4つの論点を並べます。**それぞれに状態を1行。

```
養育費        まだ入力されていません
面会交流      下書きです（お相手には見えていません）
財産分与      お相手のご返事をお待ちしています
年金分割      合意できています
```

- **数字は出さない**（相談一覧と同じ規律）
- 何も無いときは第1弾の L-2「全部を決める必要は、ありません。」を使う
- **順番に埋める必要はありません。**そう見える作り（1／4 のような進捗表示）にしない

### 2.3 ★ A-2. 論点ごとの画面 — **仮案を作って、了承してもらう**

**片方が仮案を作り、もう片方が了承します。**
双方が独立に記入して一致を待つ形ではありません（そんな一致は起きないため）。

| 状態 | 出るもの |
| --- | --- |
| **未入力** | 入力フォーム |
| ★**下書き** | 入力した内容 ＋ **直す** ＋ **お相手に見ていただく**。**まだ相手には見えていない** |
| **お相手のご返事待ち** | 渡した内容 ＋ **取り下げる** |
| **お相手から別の案** | 2つの案 ＋ 算定表の範囲（養育費のみ）。**例外的な経路** |
| **合意済** | 合意の表示（第1弾 N-1）＋ **変更を申し出る**（第1弾 K-6） |
| ★**取り下げました** | 下書きに戻る。**取り下げたことは相手にも見えている** |

### 2.4 ★ 共有は、作った側が切り替えます

| 操作 | 意味 | 相手に見えるもの |
| --- | --- | --- |
| **既定** | **下書き。自分だけ** | **何も見えない** |
| **ON にする** | お相手に見ていただく | 「お相手が、養育費の案を作られました」 |
| **OFF に戻す** | **取り下げ** | **「取り下げられました」** |

> ★ **「見ていない状態」には戻せません。**
> OFF に戻せるスイッチは**取り消せるように見えます。**
> これは「届きません」→「直接届きません」と同じ問題です。
> **操作の見た目が、実際にできることより多くを約束してしまう。**

文言の案：

```
まだお相手には見えていません。

［ お相手に見ていただく ］

お渡ししたあとで取り下げることもできますが、
一度ご覧になったことは取り消せません。
```

### 2.5 ★ 了承する側の画面

**この画面をお願いしたい。**相手が作った案を受け取った側です。

- **了承する**（→ 合意）
- **別の案を出す**（→ 例外的な経路。§3.2）
- **算定表の範囲**を、同じ画面に置ける（養育費のみ）

**了承が自然な行動に見えること。**ただし**押させる作りにしないこと**（合意は取り消せません）。

### 2.6 入力する項目

| 論点 | 項目 |
| --- | --- |
| **養育費** | 月額・支払日・いつまで |
| **面会交流** | 回数・曜日・第何週・時間・受け渡し場所 |
| **財産分与** | **一括で支払う／清算済み／別途協議する** の3択。一括なら金額と期限 |
| **年金分割** | **分割する／しない**。分割するなら按分割合（**0.5 か「別途協議」の2択のみ**） |

> ★ 財産分与に**内訳（不動産・預貯金・保険）は持ちません。**
> 内訳を持てば条項も内訳ごとに要ります。**扱えないものを入口に出さない**という規律です。

### 2.7 ★ A-3. 途中で足りない情報を伺う

養育費を入力しようとしたとき、算定表に要る情報が無ければ**その場で伺います。**

```
養育費を入力する
  ↓ お子さんが未登録なら
  お子さんのこと（人数・生まれ年月）
  ↓ 同居が未回答なら
  同居（受け取る側を決めるためだけ）
  ↓ 年収が未入力なら
  年収（第2弾の帯の解をそのまま）
  ↓
  月額・支払日・いつまで
```

- **いずれも飛ばせます。**飛ばすと算定表の範囲が出ないだけです
- **「目安が出ないと決められません」とは書きません。**実質的な強制になります

## 3. ★ いちばん難しいところ（ここを解いてほしい）

### 3.1 フォームなのに、詰問に見えないこと

このアプリは第1弾から**フォームを避けてきました。**
「離婚を考えている人に、いきなり項目を並べるのは詰問になる」からです。

**今回は真正面からフォームを出します。**方針として決めたことです。
そのうえで、**詰問に見えない入力画面**を作っていただきたい。

守っていただきたいこと：

- 必須の印（`*`）を使わない
- 進捗（1／4、○○%）を出さない
- **飛ばせることが、飛ばす前に見えている**
- エラーで赤くしない（第1弾の規約どおり）

### 3.2 ★「渡す前」と「渡したあと」が、はっきり違って見えること

**下書きは、相手に見えていません。**これが伝わらないと2通りに失敗します。

| 誤解 | 起きること |
| --- | --- |
| 見えていると思い込む | **書けなくなる。**下書きは考えるための場所なのに |
| 見えていないと思い込む | **渡したつもりがない。**相手は待っている |

- 下書きの状態が、**一目で分かること**
- 渡す操作が、**押し間違いにならないこと**（ただし重々しくもしない）
- ★ **「見ていない状態には戻せない」ことが、渡す前に読めること**

### 3.3 「別の案が出た」を、対立に見せないこと

了承せず、相手が別の案を出したときです。**例外的な経路ですが、いちばん危うい。**

素直に並べると、こうなります。

```
  あなたの案    月 5万円
  お相手の案    月 3万円        ← ★ 対立の構図。交渉の場に見える
```

第1弾の規律に **「どちらが譲ったという構図を作らない」** があります。
**この規律を保ったまま、違いが分かる見せ方**をお願いしたい。

参考：この画面には算定表の範囲（例：「月4万〜6万円の範囲とされています」）も
出せます。**第三者の目安があること**は、対立をやわらげる材料になるかもしれません。

### 3.4 財産分与・年金分割は、生々しい

養育費と面会交流は「子どものこと」ですが、**この2つは夫婦のお金の清算**です。

- 事務的すぎると冷たい
- やわらかすぎると不誠実（**軽い話ではない**）

とくに **年金分割は、多くの人が制度を知りません。**
「按分割合」と書かれても何を聞かれているか分からない。
**何のための質問なのかが、聞く前に分かる**形にしてください。

> ★ 制度上の扱いを開発側で一次資料まで確認中です。
> **確認できるまで「手続きは年金事務所でご確認ください」の注記を外しません。**
> 注記が入る前提でレイアウトしてください。

### 3.5 「決まったこと」と「取り決め」が別物だと分かること

名前が似ています。

| | |
| --- | --- |
| **取り決め** | **公正証書に入れる内容。**変えるには相手の同意が要る |
| **決まったこと** | **相談で決まったこと。**今回だけの約束・費用の分担など |

タブが並んだときに混ざらないようにしたい。

## 4. B. オンボーディング（3枚に削る）

### 4.1 いまと、これから

| いま | これから |
| --- | --- |
| 状況の確認（5択） | **やめる**（全員が入力から始まるので、分岐する意味が無い） |
| 同居 | **取り決め画面へ**（§2.5） |
| お子さん | **取り決め画面へ** |
| 年収 | **取り決め画面へ** |
| メールの登録 | **残す** |
| （招待は後回しだった） | ★**オンボーディングに戻す** |

### 4.2 3枚

| | 画面 | 中身 |
| --- | --- | --- |
| 1 | アプリの説明 | **「書いた言葉は、そのままお相手に届きません」** |
| 2 | メールの登録 | 次に使うときのため。**飛ばせる** |
| 3 | **お相手を招待しますか** | いま渡す／あとにする |

### 4.3 ★ 招待を戻すにあたって

第3弾では「招待をオンボーディングから外す」と決めました。
理由は **「聞いた時点で、アプリが相手に伝える前提でいることが伝わる」**。

**今回それを戻します。**当時の懸念は残るので、次を守ってください。

- 関係の状態（話しているか等）を**一切聞かない**
- **「あとにする」を同じ重さで置く**（枠線・面積・文字サイズを揃える）
- **「お渡しになるまで、お相手には何も届きません」**をその場に書く

## 5. C.「決まったこと」（旧「これから」）

**引き算だけです。**新しい要素はありません。

### 5.1 名前が変わります

**「これから」→「決まったこと」**

中身が「これから起きること」から**「決まったことの記録」**に変わったためです。
「これから」のままだと**予定表だと思われます**（スコープ外にしたもの）。

### 5.2 ★ 外すもの

| 外すもの | 理由 |
| --- | --- |
| 毎月の支払日・会う日 | **予定を管理しない。**スケジュール管理はこのアプリの役目ではない |
| 履行の記録（支払いました／確認しました） | **手間で押されない。**押されないと「確認できていません」と出て、**実際は払っているのに疑いが立つ** |
| 逸脱の検知・先取特権の説明 | 上に伴い出番が消える |
| リマインド | **督促になる** |

> **記録率が低い台帳は、正しい信号より誤った信号を多く出します。**出さないほうがよい。

### 5.3 残るもの

```
決まったこと
  8月22日 ／ 送迎              お約束として控えています
  9月3日  ／ 14時 小学校 父母会  お約束として控えています
  ──────────────────────────
  今回だけ 曜日 日曜日 に変更（面会交流）
  取り決めそのものは変わっていません。
```

### 5.4 空のとき

```
お話し合いで決まった予定が、ここに並びます。
ご自身で入力していただく必要はありません。

・お会いになる日を変えたとき
・費用の分担が決まったとき
・送り迎えなど、その回だけのお約束
```

> 現行の末尾にある「予定を思い出させる通知は、設定で切れます。」は **外します。**
> リマインドをやめるので、**できないことを書かない。**

---

## 5.5 ★ 場所だけ描いておきたいもの — 公正証書そのもの

**今回は実装しません。**ですが**置き場所だけデザインに入れてください。**
あとから足すと、取り決め画面を作り直すことになります。

アプリが作るのは**原案**です。実際の公正証書は公証役場で作られる紙になります。
**その完成物（PDF・写真）を預かれる**と、取り決め画面が**正典の置き場所**になります。

置きたいもの：**取り決め一覧の下（または上）に1枠**

```
公正証書

  まだお預かりしていません
  公証役場でお作りになったものを、ここに置いておけます。

  ［ 選ぶ ］
```

守っていただきたいこと：

- **中身は読みません。**「自動で読み取ります」と書かない
  （★ 読み取って項目にしたら、**今回やめた「AI が取り決めを作る」に逆戻り**します）
- **食い違ったら、預かった公正証書が正**。アプリ側は**「原案」と書き続ける**
- 本籍・住所・氏名が載るものです。**軽く扱う見た目にしない**

## 6. 変えていただきたくないこと

第1弾〜第3弾で確定しているものは、**そのまま使ってください。**

- 配色・タイポグラフィ・余白・角丸・モーション・タップ領域
- 文言規約（**使ってはいけない語**を含む）
- カピバラのマークとサイズ規約
- **年収の帯の見せ方**（第2弾の解）
- タブバー（5つ。うち1つが「これから」→「決まったこと」に**名前だけ**変わる）

## 6.1 画面に出してはいけないもの

| | 理由 |
| --- | --- |
| 慰謝料 | **対象外と決定** |
| 離婚への同意・親権者・婚姻費用 | **扱える設計になっていない。扱えないものを入口に出さない** |
| 領収書などの画像の添付 | 未実装（Issue） |
| 面会の実施記録 | 未実装（Issue） |
| 口座連携・入金の自動確認 | **入金を観測できない**という前提を捨てることになる |
