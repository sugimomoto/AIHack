## ★ 本番だけがデータを読めていなかった

Cloud Run の Service Account に **`roles/datastore.user` が付いていなかった。**

```
⨯ Error: 7 PERMISSION_DENIED: Missing or insufficient permissions.
```

S0 では Secret Manager の権限だけを付けており、**Firestore の権限が漏れていた。**
ヘルスチェックも画面表示も Firestore に触れないため、**デプロイは成功し続けていた。**

→ 付与し、**Terraform にも記載した**（構成をコードで持つ）。

> **「デプロイできた」は「動いた」ではない。**
> データに触れる経路を1つ通すまで、確認したことにならない。

## 設計上の記録

### なぜパスワードを持たないか

このアプリは住所・年収・子の情報を持つ。
**漏れて困るものを、そもそも預からない。**

有効な招待トークンを持っていること自体が本人性の根拠である（C-04）。
**招待を経ずにセッションは作れない。**

### 解決の順序

```
1. セッション Cookie      ← 本番の主経路
2. Authorization ヘッダ   ← 将来の外部連携用
3. 開発用の切替           ← ★本番では常に無効
```

逆にすると、**認証済みのユーザーがヘッダで別人になれる。**
