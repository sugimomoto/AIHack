## 0. 何を見せるか

**このアプリの主張は1つです。**

> **メッセージを転送しない。**
> 父は AI と話し、母も AI と話す。**書いた言葉そのものは、決して相手に届かない。**

デモは、この1点が**実装として本当か**を見せるものにします。
機能を並べません。**確かめられる形で見せます。**

---

## 1. 筋書き（4分／⑥まで入れて4分半）

### ① C1 — 書いた言葉が、相手に届かない（60秒）

**2つのブラウザを並べます。**左が A さん、右が B さん。

A さんの画面に、そのまま打ちます。

```
また勝手に土曜に決めやがって。こっちだって必死なんだよ
```

- **A の画面**：受け止めが返る。「こう伝わりました」が並ぶ
- **B の画面**：**原文がどこにも無い。**伝聞形の要約だけが届く

```
面会交流の日程について、ご相談があるそうです。
土曜日のご都合が難しいとのことです。
```

> ★ここで **/context** を開きます。
> **AI に渡している材料そのもの**が表示され、相手の原文が入っていないことが見えます。
> 「安全です」と書く代わりに、**渡していないことを画面で見せます。**

### ② 取り決めは「入力」で作る（90秒）

**取り決めタブ**を開きます。4つの論点が、状態ごとに並んでいます。

```
養育費      お相手から案が届いています
面会交流    合意できています
財産分与    まだ入力されていません
年金分割    まだ入力されていません
```

**財産分与**を開いて、その場で入力します。

- 「内訳を書いていただく必要はありません」が**先に**書いてある
- 必須の印が無い。進捗も出ない。各項目に「あとでも」
- 「下書きにする」→ **画面の地が沈み、鍵つきの帯が出る**

> ★**「まだお相手には見えていません」**
> ここが今回の中心です。**下書きは、考えるための場所。**
> 見られていると思うと、書けません。

「お相手に見ていただく」を押すと、確認シートが出ます。

> ★**「お渡ししたあとで取り下げることもできますが、一度ご覧になったことは取り消せません。」**
> ボタンの下ではなく、**シートの中**に置いてあります。押す前に読まれるように。

押すと、**B の画面に現れます**（ここで右の画面に切り替え）。

### ③ 了承すると、合意になる（45秒）

B の**養育費**を開きます。封書のカードで「お相手が作られた案」。

その下に**算定表の帯**。案の 5万円が、月4万〜6万円の範囲の中にあることが見えます。

> ★**AI はこの数字に一切触れていません。**
> 算定表を引いているだけで、生成はしていません。

「この内容で了承する」→ 双方の画面が **合意済**になります。

### ④ 公正証書の原案（30秒）

**取り決め → 公正証書 → 原案を見る**

```
第1条（養育費）
  甲は乙に対し、丙及び丁の養育費として、50,000円を毎月25日限り、
  乙の指定する方法により支払う。
  前項の支払は、丙及び丁がそれぞれ20歳に達する月まで継続する。

第2条（面会交流）
  ...
```

> ★**この文面に LLM は関与していません。**
> ひな形の置換だけで作っています。置換に失敗したら**文書を出しません。**
> 空欄のある法的文書は、空欄のない誤りより危険だからです。

### ⑤ うまくいかなかったときこそ、仲介が効く（45秒）

**相談タブ →「会えなかったことを相談する」**

> ★予定どおりに進んでいるあいだ、当事者はこのアプリを必要としません。
> **困るのは、予定どおりにならなかったとき。**
> そこは直接連絡したくない相手と話さなければならない場面で、
> **仲介の価値がいちばん高い。**

書き出しの例に、**責める言い方を置いていません。**
「先月お会いできなかったので、振替をご相談したいです」

### ⑥ ★時間があれば：実データで測った話（30秒）

画面ではなく、**話す**内容です。

> 実際の共同養育のやり取り **約1,080件（9.5か月）** の提供を受けました。
> **推測せず、その文言を本物の実装に通しました。**
>
> 実データの対立は、**丁寧語のまま進みます。**
> 法的な語彙を持ち出す威嚇や、公的機関への通報を示唆する申し立て——
> 想定していた攻撃語とは形が違います。**それでも取り次がれませんでした。**
>
> ★そして、**欠陥が3つ見つかりました。**
> 臨時費用の金額が、**3回とも違う値**で取り出されていました。
> **伝聞文は正しかった**ので、目視では見つかりません。
>
> 直し方は、既存の検査を**逆向きに使う**ことでした。
> **言葉は渡さない。事実は、原文のまま。**

★ 聞かれたら `docs/implementation-status.md` §6 を開きます。

## 2. 押さえるべき台詞

| ① のあと | 「**転送していないことを、画面で確かめられます。**」 |
| ② の下書き | 「**下書きは、考えるための場所です。**見えていると書けません」 |

| ⑤ のあと | 「**了承しないときは、対案ではなく相談に行きます。**並べた時点で交渉の卓になるので」 |
| ⑥ | 「**測ったから見つかりました。**テストは全部通っていました」 |

## 3. 触られたときに備える

| 触られる場所 | 何が起きるか |
| --- | --- |
| 下書きのまま相手の画面 | **何も出ません**（サーバ側で落としています。画面で隠していません） |
| 取り下げる | 相手からは消え、**取り下げたことは相手に届きます** |
| 了承しない | 「**このことを相談する**」だけです。★**対案をフォームで返す経路を外しました**（並べた時点で交渉の卓になるため） |
| 相手の案が届いている側が渡そうとする | **409 で止まります。**画面だけでなく **API で**止めています |
| 設定の「下書きを消す」 | **渡していない自分の下書きだけ**消えます。合意済みとお渡し済みは残ります |
| 慰謝料・親権者 | **入口にありません**（扱えないものを出さない） |
| 相談で金額を書く | **取り決めは動きません**（対話から取り決めを作る経路がありません） |
