| 項目 | 内容 |
| --- | --- |
| 最終更新 | 2026-08-12 |
| 目的 | **何が動き、何が動かないかを、外から検証できる形で残す** |

---

## 0. この文書の役割

> **「作っていないもの」を書き残すことは、「作ったもの」を書くことと同じくらい重要である。**

デモや画面だけを見た人は、動いていない機能を動いていると受け取る。
本書は、**その誤解を構造的に防ぐために置く。**

### 0.1 記載の規約

| 区分 | 意味 |
| --- | --- |
| ✅ **実装済み** | 本番で経路が通っており、テストがある |
| ⚠️ **部分実装** | 一部が動くが、欠けている部分がある。**欠けている内容を必ず書く** |
| ⛔ **未実装** | 作っていない。**画面上でも「動くように見せていない」ことを併記する** |
| 🚧 **ブロック中** | 外部の回答待ち。**何を待っているかを書く** |
