## 1. 目的

> **最初の当事者がケースを作り、相手を招待できる状態にする。**

### 1.1 欠けていたもの

S20 でセッションは招待の受諾からしか発行されなかった。
**では、最初の一人はどうやって始めるのか。**

```
❌ 招待からしかセッションが出ない
     → 最初の一人が存在できない。誰も始められない。

✅ ケースの作成でもセッションが出る
     → 作った人が最初の当事者になる
```

## 3. ★ テストを先に書く対象

| 対象 | 理由 |
| --- | --- |
| **自分だけが ACTIVE になること** | 相手が勝手に参加済みになると、C1 の前提が崩れる |
