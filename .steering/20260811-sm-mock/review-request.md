## B. 離婚案件を専門とする弁護士へ

```
件名：Aida（あいだ）の画面ができました。法的な観点でご確認いただけますか

いつもありがとうございます。
先日ご相談したアプリの画面ができましたので、ご確認いただけないでしょうか。

▼ こちらです
https://aih-3jnijo1kh-aida20.vercel.app

【はじめに】
これは動作しないモックです。AIの応答はあらかじめ用意した文章で、
実際には何も処理されません。

画面の下にある「◀ ▶」で場面を進められます。全部で9場面です。
また、いちばん下の「視点」で、別居している親と同居している親の
両方の画面を切り替えて見られます。

【設計の前提】
先生のご指摘を踏まえ、以下の制約を設計に組み込んでいます。

・公正証書は公証人が作成するものとし、本アプリは原案の作成補助に留める
・条項の文面は、あらかじめ用意したひな形に合意内容を流し込む方式とし、
  AIに条項を書かせない
・養育費の金額はAIに計算させず、算定表を参照して範囲を示すだけにする
・相手の申告は「〜とのことです」と伝聞の形で伝え、AIが事実認定をしない

【お聞きしたいこと】
お時間は15分程度で結構です。1番を最優先でお願いできればと思います。

1. 【最優先】非弁行為の観点で、危うい画面や文言はありませんか。
   「法律相談をしている」と受け取られかねない箇所があれば
   ご指摘ください。

2. 8つの論点の並びと名称は、実務の感覚に合っていますか。
   （場面⑨の「取り決め」画面）

3. 「取り決め」という語を使っています。適切でしょうか。
   「合意」「協議」などとの使い分けについてもご意見をください。

4. 場面⑧に「今後も変更する＝取り決めそのものを書き換えます。
   お相手の同意が必要です」という説明があります。
   この表現は法的に正確でしょうか。

5. 養育費については、算定表の範囲を示すだけにする予定です。
   「〜とされています」という言い方で十分でしょうか。
   踏み込みすぎ、あるいは足りない点はありませんか。

6. 実際の当事者に見せたとき、誤解や紛争を生みそうな表現はありませんか。

7.【重要／画面はまだありません】
   養育費が支払われていない場合に、
   「合意額は先取特権の範囲内（子1人あたり月8万円）とされています」
   といった説明を出すことを検討しています。
   これは書きすぎでしょうか。それとも書くべきでしょうか。

8.【重要／ご相談】
   対話の中で、子どもへの危害が示唆される記述をAIが検知した場合、
   事業者として何ができる／すべきでしょうか。
   通報義務や責任の問題に触れる可能性があると考えており、
   判断がつきません。

9.【ご相談】
   利用者が退会を希望した場合、合意内容のデータをどこまで削除できるでしょうか。
   合意は法的文書の基礎になるため、単純に削除してよいものか判断がつきません。
   相手方がまだ利用を続けている場合の扱いも含めてご意見をいただけますか。

【答えなくてよいこと】
・色や書体、レイアウトの好み
・動作の速さ（モックのため実装とは無関係です）
・誤字脱字

【今後について】
制度や手続きの解説を読めるページ（協議離婚とは、公正証書とは、
算定表の読み方、2026年4月の改正内容など）を用意する予定です。
AIに個別の助言をさせない代わりに、一般的な情報は別途提供する、という考えです。

もし監修という形でお名前を出させていただけるようであれば、
別途ご相談させてください。

よろしくお願いいたします。
```
