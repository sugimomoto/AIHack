## 1. C-01｜改正民法（令和6年法律第33号）

**出典**：法務省民事局「民法等の一部を改正する法律（父母の離婚後等の子の養育に関する見直し）について」
https://www.moj.go.jp/MINJI/minji07_00357.html

### 1.1 基本情報

| 項目 | 内容 |
| --- | --- |
| 法律名 | 民法等の一部を改正する法律（令和6年法律第33号） |
| 成立 | 令和6年5月17日（同月24日公布） |
| **施行日** | **令和8年（2026年）4月1日** ※令和7年10月31日閣議決定・11月6日公布 |
| 関連省令 | 民法第308条の2の規定による子の監護費用の先取特権に係る額の算定等に関する省令（令和7年法務省令第56号、令和7年12月12日制定） |

> **事前メモの「2026年4月1日施行」は正しい。**本日（2026-08-11）時点で施行から約4ヶ月が経過している。

### 1.2 改正の全体像

法務省の資料は改正を5つに整理している。

| # | 分類 | 主な内容 |
| --- | --- | --- |
| 第1 | 親の責務等 | 婚姻関係の有無にかかわらず父母が子に負う責務を明確化（民法817の12） |
| 第2 | 親権・監護等 | 離婚後の親権者の規律見直し、**親権行使の規律整備**、監護の分掌 |
| 第3 | **養育費の履行確保** | **先取特権の付与、法定養育費制度**、執行手続のワンストップ化、収入情報の開示命令 |
| 第4 | 安全・安心な親子交流 | 親子交流の試行的実施、**婚姻中別居の場面における親子交流**、祖父母等と子の交流 |
| 第5 | その他 | **財産分与の請求期間を2年→5年に伸長**、寄与割合は原則2分の1ずつ |

### 1.3 法定養育費制度【新設】

| | 内容 |
| --- | --- |
| 改正前 | 養育費の支払を請求するには、額についての**取決めが必要** |
| 改正後 | **取決めがなくても**、離婚時から一定額の法定養育費を請求できる（民法766の3） |
| **金額** | **月額2万円 × 子の数**（子2人なら月4万円、3人なら月6万円） |

条文上は「子の最低限度の生活の維持に要する標準的な費用の額その他の事情を勘案して……法務省令で定めるところにより算定した額」とされ、省令でこの額が定められた。

### 1.4 養育費債権への先取特権【新設】

| | 内容 |
| --- | --- |
| 改正前 | 取決めがあっても、財産を差し押さえるには**債務名義（公正証書や調停調書など）が必要** |
| 改正後 | 養育費債権のうち一定額に**先取特権（優先権）**を付与（民法308の2）。**一定額までは債務名義がなくても差押えが可能**で、かつ他の一般債権者に優先して弁済を受けられる |
| **上限額** | **月額8万円 × 子の数**（子2人なら月16万円まで、3人なら月24万円まで） |

### 1.5 経過措置（改正法附則）

| 対象 | 経過措置 |
| --- | --- |
| 養育費債権の先取特権（附則3条1項） | **施行日前に取決めがされた場合も**、施行日以後に生じた各期の定期金に適用される |
| 法定養育費（附則3条2項） | **施行日前に離婚した場合等には適用されない** |
| 親権者変更（附則6条） | 施行日前の申立てでも、判断時期が施行日後なら単独親権→共同親権への変更が可能 |

> **法定養育費は2026年4月1日以降に離婚した層にしか適用されない。**既に離婚済みの層（毎年約20万人の子が新たに発生する累積ストック）には及ばない。

### 1.6 ⚠️ 訴求への影響【要対応】

**成立しなくなった訴求**

> ❌「公正証書がないと養育費を強制執行できない」

先取特権により、**子1人あたり月8万円までは債務名義なしで差押えが可能**になった。取り決めをしている母子世帯の養育費の平均月額は50,485円（→ §2.3）であり、**典型的な水準は8万円の枠内に収まる**。したがって「差押えのために公正証書が必要」という訴求は、多くのケースで成立しない。

**新しい訴求**

> ✅「**取り決めをしないと、子1人あたり月2万円しか請求できない**」

法定養育費（月2万円/子）は「**子の最低限度の生活の維持**」に要する額として設定されたものであり、算定表に基づく適正額ではない。

| ケース | 請求できる額 |
| --- | --- |
| 取り決めなし | **月2万円 × 子の数**（法定養育費） |
| 取り決めあり | 合意額（うち月8万円/子までは債務名義なしで差押え可） |

**取り決めをしている世帯の平均月額は50,485円**（→ §2.3）。子1人であれば法定養育費との差は月3万円前後、年約36万円になる。

> ※ 平均月額50,485円は子の数が異なる世帯を含む平均値であり、法定養育費（子の数に比例）との厳密な1対1比較ではない。プレゼンで用いる際はこの点に注意する。

**この転換は、むしろプロダクトにとって有利である。**改正前は「取り決めをしないと不安」という曖昧な訴えしかできなかったが、改正後は「**取り決めがない場合のデフォルト値が月2万円と法定された**」ため、取り決めの有無による差額を数字で提示できるようになった。

### 1.7 ★ 見落としていた最大の追い風：共同親権は継続的な合意形成義務を生む

改正法第2の2（民法824の2等）は、親権行使について次のように定めている。

> 父母双方が親権者であるときは**共同行使する**こととしつつ、**親権の単独行使が可能な場合を明確化**
> ・子の利益のため**急迫の事情**があるとき（DV・虐待からの避難、緊急の場合の医療等）
> ・**監護及び教育に関する日常の行為**（子の身の回りの世話等）
>
> 父母の意見対立を調整するための**裁判手続を新設**

これが意味すること：

| | 単独親権（従来） | 共同親権（改正後の選択肢） |
| --- | --- | --- |
| 離婚後の意思決定 | 親権者が単独で完結 | **日常の行為と急迫の事情を除き、双方の合意が必要** |
| 必要な連絡 | 養育費と面会交流のみ | **上記＋進学・医療・転居等の重要事項のたびに合意形成** |
| 対立時 | — | **裁判手続が新設された**（＝対立の発生が制度上想定されている） |

**共同親権を選択した父母は、離婚後も継続的に合意形成をし続けなければならない。**しかも国が「意見対立を調整するための裁判手続」をわざわざ新設したということは、**対立の発生が制度設計の前提になっている**。

> **これは本プロダクトの月額課金（継続利用）の根拠そのものである。**離婚後に連絡が必要な場面が、法律によって構造的に増えた。requirements.md §1.1 は「共同親権を選択できるようになった」としか記述しておらず、この点を反映できていない。

### 2.5 ★ 決定的な発見

#### ① 取り決めをしない最大の理由は「相手と関わりたくない」

こども家庭庁（当時厚労省）の調査本文より：

> **養育費**の取り決めをしていない最も大きな理由については、母子世帯の母では「**相手と関わりたくない**」が最も多く、次いで「相手に支払う意思がないと思った」

> **親子交流（面会交流）**の取り決めをしていない最も大きな理由については、母子世帯の母では「**相手とかかわりたくない**」が最も多く、次いで「取り決めをしなくても交流ができる」

**養育費・面会交流の両方で、取り決めがされない理由の第1位が「相手と関わりたくない」。**

本プロダクトが解決しようとしている課題が、**国の公式調査によって課題の第1位として特定されている**。課題の実在性（審査項目1）の裏づけとして、これ以上のものはない。

#### ② 協議離婚こそが、取り決めがされない場所

**養育費の取り決め率（母子世帯・離婚方法別）**

| 離婚方法 | 世帯数 | 取り決めをしている |
| --- | --- | --- |
| **協議離婚** | 758,312 | **43.6%** |
| その他の離婚（調停・審判・裁判） | 192,146 | **81.2%** |
| 未婚 | 128,755 | 13.6% |

**面会交流の取り決め率（母子世帯・離婚方法別）**

| 離婚方法 | 取り決めをしている |
| --- | --- |
| **協議離婚** | **27.9%** |
| その他の離婚 | **56.5%** |

調査本文にも明記されている：

> 「協議離婚」は、「その他の離婚」と比べて養育費の「取り決めをしている」割合が低くなっている
> 「協議離婚」は、「その他の離婚」と比べて親子交流（面会交流）の「取り決めをしている」割合が低くなっている

**裁判所という第三者が介在すれば取り決め率は約2倍になる。しかし最も件数の多い協議離婚では、第三者が介在しない。**

> **これが本プロダクトの存在理由そのものである。**
> 「協議離婚に、AIという第三者を介在させる」——この一文が、統計によって直接裏づけられた。

| 相談先 | 割合（相談した人の中で） |

## 3. C-03｜非弁行為（弁護士法72条）

**出典**：法務省大臣官房司法法制部「AI等を用いた契約書等関連業務支援サービスの提供と弁護士法第72条との関係について」
https://www.moj.go.jp/content/001400675.pdf

### 3.1 判断枠組み

弁護士法72条違反となるのは、次の**3要件すべてに該当する場合**。いずれか1つでも該当しなければ違反しない。

| # | 要件 | 内容 |
| --- | --- | --- |
| 1 | **報酬を得る目的** | 対価関係が実質的に認められるか。現金に限らず、額の多少を問わない。**第三者から受け取る場合も含む** |
| 2 | **法律事件（事件性）** | 法律上の権利義務に関し争いや疑義があり、又は新たな権利義務関係の発生する案件 |
| 3 | **鑑定その他の法律事務** | 「鑑定」＝法律上の専門的知識に基づき法律的見解を述べること |

さらに、3要件すべてに該当する場合でも、**弁護士・弁護士法人に提供し、弁護士が自ら精査・修正する方法で利用するとき**は違反しないとされている（ガイドライン4）。

### 3.2 ⚠️ 離婚協議には「事件性」が認められる

ガイドラインは事件性について次の例を挙げている。

> 例えば、**取引当事者間で紛争が生じた後に、当該紛争当事者間において、裁判外で紛争を解決して和解契約等を締結する場合**には、法律上の権利義務に争いがあり、あるいは疑義を有するものとして「**事件性**」が認められる

**離婚協議はまさにこれに該当する。**当事者間に争いがあり、裁判外で解決して合意（公正証書）を締結する場面である。したがって**要件2は満たされてしまう**と考えるべき。

企業法務の通常の契約締結（事件性なし）とは状況が異なるため、**「AI契約書レビューはOKだから離婚合意もOK」という類推は成り立たない。**

### 3.3 ⚠️ 契約書等の作成支援における線引き

ガイドラインは、契約書作成支援サービスを2つに区別している。

| | 内容 | 判定 |
| --- | --- | --- |
| **ア** | 利用者の**非定型的な入力**に応じ、個別の事案における契約に至る経緯や背景事情、内容等を**法的に処理して**、当該処理に応じた**具体的な契約書等が表示される**場合 | 「法律事務」に**該当し得る**（＝リスクあり） |
| **イ** | 定型的な入力または選択肢の選択により、**あらかじめ登録された複数のひな形から特定のひな形が選別されてそのまま表示される**か、選別されたひな形に**入力内容が反映されて変更表示されるにとどまる**場合 | 通常「法律事務」に**該当せず、違反しない** |

**LLMに条項を自由生成させる設計は「ア」に該当し得る。**

### 3.4 ★ 設計制約【要対応】

以上より、本プロダクトには次の制約を課す必要がある。

| # | 制約 | 根拠 |
| --- | --- | --- |
| **L-1** | **公正証書原案の生成において、LLMに条項文を自由生成させない。**あらかじめ用意した条項ひな形を選別し、合意された構造化データ（金額・日付・頻度等）を流し込むにとどめる | ガイドライン3(1)イ |
| **L-2** | **AIは法的見解を述べない。**算定表については「一般にこの範囲とされている」という**客観的情報の提示**に留め、「あなたはこうすべき」という個別助言を行わない | 「鑑定」の定義 |
| **L-3** | **公正証書は公証人が作成する**という二段構えを維持し、生成物が原案（メモ）に過ぎないことを画面上に明示する | — |
| **L-4** | 将来の専門家連携（行政書士・弁護士）は、非弁リスクの回避策としても機能する | ガイドライン4 |

> **L-1は、既存の設計と自然に整合する。**FR-05（合意状態の管理）で合意内容が構造化データとして保持されているからこそ、条項生成をひな形ベースにできる。**「LLMに条項を書かせない」という制約を自ら課している**ことは、プレゼンにおいて強い設計判断として提示できる。

## 4. 訴求文の再構成

調査結果を踏まえた、プレゼン冒頭で使う課題提示の骨子。

```
① 離婚の87.5%は協議離婚。裁判所も代理人も介在しない
        ↓
② 協議離婚の養育費取り決め率は43.6%。
   裁判所を経れば81.2%。第三者が入るかどうかで倍の差
        ↓
③ 取り決めをしない理由の第1位は「相手と関わりたくない」
   （こども家庭庁 令和3年度調査）
        ↓
④ 結果、養育費を現在も受けている母子世帯は28.1%
   受けたことがない世帯が56.9%
        ↓
⑤ 2026年4月の法改正で、取り決めがない場合は
   月2万円（子1人）の法定養育費のみ。
   取り決めをしている世帯の平均月額は50,485円
        ↓
⑥ さらに共同親権を選ぶと、離婚後も重要事項のたびに
   双方の合意が必要になる（民法824の2）
        ↓
【結論】協議離婚に、AIという第三者を介在させる
```
