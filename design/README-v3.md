---

## 1. なぜ作り直すのか

第2弾までの入口は、**全員が同じ画面から始まる**作りでした。

```
はじめる →「お子さんと同居していますか」→ 招待 → 相談
```

しかし実際には、状況が大きく異なる人が来ます。

| | **取り決めがある** | **取り決めがない** |
| --- | --- | --- |
| **離婚前** | 条件は決まった。書面にしたい | **条件を整理したい** |
| **離婚後** | **すでにある取り決めを入れて、運用に入りたい** | **いま決めたい**（最も多い層） |

さらに横断で「**まだ相手とは話していない**」層がいます。

> ⚠️ **この層に「お相手を招待してください」と出した時点で、離脱します。**
> まだ相手に知られたくない段階だからです。

---

## 2. ★ 設計上の制約（守っていただきたいこと）

### 2.1 状況を聞くことが、詰問にならないこと

「離婚していますか」「取り決めはありますか」は、**答えたくない問いになりえます。**

- 選択肢を**淡々と並べる**（どれかが望ましい、という見え方にしない）
- 「まだ決まっていない」を**恥ずかしくない選択肢**にする
- 進捗バー・ステップ数を出すかどうかも含めてご判断ください
  （出すと「あと3つも答えるのか」になり、出さないと終わりが見えません）

### 2.2 聞く順序

**負担の軽いものから重いものへ**という原則で並べていますが、より良い順序があればご提案ください。

```
① 状況（選ぶだけ）
② 同居（選ぶだけ）
③ お子さん（人数・生まれ年月）
④ 年収（★最も抵抗が大きい）
⑤ すでにある取り決め（該当者のみ・飛ばせる）
⑥ お相手を招待（該当者のみ）
```

### 2.3 ★ 年収の画面は第2弾の解をそのまま使ってください

第2弾でいただいた「**入力した額と、相手に見える帯を並べて示す**」は非常に効いています。

```
入力した金額        →     お相手に見えるのは
4,380,000円               425〜450万円
```

### 2.4 お子さんの画面

- **必要なのは人数と年齢だけ**です。生まれ**月**まで伺えば足ります
- **名前は任意**にしてください。必要のない情報を求めない
- 1〜3人。**4人以上は算定表が公表されていないため、目安を出せません**
  → 3人に達したときに、その旨をどう伝えるか

### 2.5 「すでにある取り決め」の画面

- **お相手の確認を求めません**。記録すること自体が、その人の意思表示です
- お相手も同じ内容を記録したときに、はじめて合意になります
- **これをどう伝えると、負担にも不安にもならないか**をご検討ください
- **飛ばせること**が必須です（うろ覚えの人がいます）

### 2.6 相手側にも同じことを聞く必要があります

**算定表は双方の年収で引きます。**
招待を受諾した側にも、お子さん（未登録なら）と年収を伺います。

> **受諾した直後の人は、まだ何も納得していません。**
> 第2弾の A-3（受け取った側の最初の画面）で「参加しない選択もできます」と伝えたあとに、
> いきなり年収を聞くことになります。**この接続をどう作るか**が今回いちばん難しいところです。

## 4. 変えていただきたくないこと

| # | |
| --- | --- |
| 1 | **確定済みのデザイントークン**（README-v1 の値） |
| 2 | **カピバラに表情差分を作らない**（監視感が生まれる） |
| 3 | **「ここに書いたことは、お相手には届きません」の表示**（プロダクトの約束） |
| 4 | 語彙（→ [docs/glossary.md](../docs/glossary.md) §4）。**「違反」「未払い」「元夫／元妻」を使わない** |
| 5 | **入力欄を常に開いておく**（トピック選択を必須にしない） |
