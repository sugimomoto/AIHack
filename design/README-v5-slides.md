## 0. お願いしたいこと

**動画は、画面録画が主役です。**スライドは、その**あいだに挟む**ものです。

> ★ **スライドで説明しない。**画面で見せられることは、画面で見せます。
> スライドは、**画面では見えないもの**——構造・数字・判断——だけを担います。

| | 枚数 | 役割 |
| --- | --- | --- |
| **A. 導入** | 3枚 | 何のアプリか／なぜ要るのか |
| **B. 仕組み** | 3枚 | ★**最重要。**画面では見えない構造 |
| **C. 締め** | 1枚 | 何を作ったか |

**合計7枚。**足りなければ **B を優先**してください。

---

## 1. ★ 大前提：この動画の主張

**1行に絞ると、これです。**

> ★ **言葉は渡さない。事実は、原文のまま。**

スライド全体が、この一文に向かって進みます。**逆に、これ以外の主張を足さないでください。**

### ★ 言い方の向きを、間違えないでください（最重要）

このプロダクトは長らく「**メッセージを転送しません**」を看板にしていました。
**やめました。**否定を看板にすると、**「届かないなら意味がない」**と読まれるからです。

| ✗ 使わない | ✓ 使う |
| --- | --- |
| メッセージを転送しません | **角の立つところは、外してお伝えします** |
| 相手には届きません | **そのままでは届きません。整えてお伝えします** |
| 関わらずに決められる | **直接やりとりしなくても決められる** |

> ★ **やっているのは「伝えること」です。**転送しないのは、そのための手段にすぎません。
> **否定を単独で置かない。**書くなら必ず**対で**書いてください。

## 2. A. 導入（3枚）

### A-1｜これは何のアプリか

**入れてほしい要素**

- タイトル：**Aida（あいだ）**
- 一行：**離婚した父母が、別々に暮らしながら、子どもを一緒に育てていくためのアプリ**
- ★ **AIの立ち位置を、図で1つだけ**

```
一般的なAIチャット     人 ⇄ AI          （AIは相談相手）
★Aida                 人 ⇄ AI ⇄ 人     （AIは、書き直して届ける通訳）
```

★ **この2段の対比が、A-1の主役です。**文字を減らしてでも、ここを大きく。

### A-2｜なぜ要るのか（数字）

**4つだけ。増やさないでください。**

```
離婚の 87.5%          協議離婚。裁判所も代理人も入らない
取り決め率 43.6%      → 第三者が入れば 81.2%
取り決めをしない理由   第1位「相手と関わりたくない」
実際のやり取り         1年半で約1,000件。★8割以上が事務連絡
```

★ **強調するのは3行目**です。**お金がないからでも、制度を知らないからでもない。**
そして4行目で「**離婚しても連絡は終わらない**」に接続します。

出典：全国ひとり親世帯等調査（こども家庭庁）。**小さくで構いませんが、必ず入れてください。**

### A-3｜何が起きるのか（入出力）

★ **このスライドが、動画でいちばん効きます。**

```
父が書いたもの
  月3万が限界。こっちだって仕事切られて必死なんだよ。
  そっちだって働いてるだろ、少しは考えろ

        ↓

母の画面に届くもの
  養育費について、月額3万円までを希望されているそうです。
  背景として、現在は職を失っているとのことです。
```

**演出のお願い**

- 上下2段。**上が生の言葉、下が届いたもの**
- ★ **消えた部分を、消えたと分かるように**（「必死なんだよ」「少しは考えろ」に取り消し線か、薄く）
- ★ **残った部分を強調**：**「月3万円」**と**「仕事を失った」**
- 一文添える：**大事なのは、届かなかったことではなく、届いたことです**

> ★ 上を赤、下を緑のような**善悪の対比にしないでください。**
> 生の言葉は**悪ではありません。**そのままでは送れないだけです。

## 3. B. 仕組み（3枚）★ ここが本体

### B-1｜どこに何が置かれているか

**画面では絶対に見えない**ので、スライドでしか示せません。

```
   父の相談 ──┐
              ├──▶ 取次ぎ（from / to）──▶ 相手の画面
   母の相談 ──┘

   父の原文 ┈┈✗┈┈▶ 母の画面     ★到達する経路が存在しない
```

- 相談は、**当事者ごとに別のドキュメント**です（物理的に分かれています）
- ★ **点線は「実装されていない経路」**であることが伝わる描き方にしてください
- 一文：**「見せない」のではなく、「同じ場所に無い」**

### B-2｜LLM は「書く」のではなく「取り出す」★最重要

```
原文  「月3万が限界。仕事切られて必死なんだよ」
          │
          ▼
   LLM がやること … 枠を埋める（書かない）
          │
          ├─▶ amountText : 「月3万」   ★原文の表記のまま
          └─▶ context    : 「現在は職を失っている」
          │
          ▼
   定型の枠   ｛論点｝について、｛要約｝
              背景として、｛事情｝
          │
          ▼
   相手に届く文章   ★組み立てるのは、こちら
```

**添える一文**

> ★ **LLM に、解釈をさせません。取り出させるだけです。**
> 「15万」は `150000` ではなく、**「15万」のまま**受け取ります。

★ **`amountText:「月3万」` を、数値に変換しないでください。**
ここを `30000` と描くと、**このスライドの主張が反対になります。**

### B-3｜対になる、2つの検査

```
                 ┌──▶ 相手が読む文章   ★原文と逐語一致してはならない
   同じ原文 ─────┤
                 └──▶ 金額・日付の値   ★原文に逐語で書かれていなければならない
```

- **同じ道具（逐語一致）を、片方では禁止に、もう片方では必須に**使っていることが伝わる形に
- ★ **左右対称**に描いてください。対になっていることが図の主張です
- 大きく一文：

> ★ **言葉は渡さない。事実は、原文のまま。**

## 4. C. 締め（1枚）

### C-1｜何を作ったか

```
目的   離婚しても、子どもが健やかに育つための基盤になる
手段   親同士が直接やりとりしなくても、決めて・運用できるようにする
道具   取り決めの記録、公正証書のドラフト
```

★ **「道具」を大きくしないでください。**公正証書は入口であって、本質ではありません。

最後に一行：

> **転送しないことが達成ではありません。達成は、伝わったことのほうです。**

## 5. 見た目のルール（既存に合わせてください）

**新しいトーンを作らないでください。**アプリと同じ世界に見える必要があります。

| | |
| --- | --- |
| 色 | ★**アプリの CSS 変数をそのまま**（`--surface` / `--text-sub` / `--agree` / `--border-dashed`） |
| 地色 | 生成りの `--surface-2`。**白地にしない** |
| 強調 | ★**色数を増やさない。**合意・肯定は `--agree` 系のみ |
| 角丸 | カードは `--r-lg`、要素は `--r-md` |
| キャラクター | カピバラは **A-1 と C-1 だけ。**仕組みの説明には出さない |
| 書体 | アプリと同じ。**明朝を混ぜない** |

### ★ 動画で使うための制約

- **16:9**、フルHD（1920×1080）
- ★ **文字は大きく。**1枚あたり**日本語120字以内**を目安に
- ★ **アニメーションは要りません。**静止画で構いません（切り替えは編集側でやります）
- 画面録画と交互に出るので、**1枚あたり10〜20秒**で読み切れる量に

---

## 6. ★ 描いてはいけないもの

| | 理由 |
| --- | --- |
| **実在の人物・具体的な家庭** | 実データは Git 対象外。**記事にも出していません** |
| 「未払い」「督促」「証拠」 | ★**このアプリは入金を観測できません。**書けば嘘になります |
| 既読・通知・バッジ | **持っていません。**急かさない約束（AC-06） |
| メールで招待する絵 | ★**やめた機能です** |
| 「AIが金額を提案」 | ★**金額は当事者が入力します。**AIは触れません |
| 泣いている子ども・争う夫婦 | ★**扇情的にしない。**当事者が見て、責められた気持ちにならないこと |

---

## 7. 優先順位（間に合わない場合）

1. ★ **B-2**（LLM は取り出すだけ）— これが無いと技術的な主張が立ちません
2. ★ **A-3**（入出力）— これが無いと何のアプリか伝わりません
3. **B-3**（対になる検査）
4. A-1 / A-2
5. B-1 / C-1

★ **1と2だけでも、動画は成立します。**
