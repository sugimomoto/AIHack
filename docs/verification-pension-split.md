## 1. ★ いちばん大事な発見

**「按分割合の上限は2分の1」とは、一次資料に書かれていない。**

書かれているのはこうである。

> 按分割合を定めるために、当事者は分割の対象となる期間やその期間における
> 当事者それぞれの標準報酬月額・標準賞与額、**按分割合を定めることができる範囲**などの
> 情報を正確に把握する必要があります。このため、当事者双方または一方からの請求により、
> 合意分割を行うために必要な情報（「**情報通知書**」）を提供しています。

つまり、**定められる範囲はケースごとに決まり、情報通知書で知らされる。**
一律の数字ではない。

### 実装への反映

| | |
| --- | --- |
| **やめたこと** | 「割合には上限があるとされています」と書くこと。**一次資料に無い** |
| **書いたこと** | 「分ける割合を決められる範囲は、年金事務所が出す『情報通知書』で分かります」 |
| **足したこと** | 請求期限（原則、離婚の翌日から5年以内） |

> ★**書かれていないことを、アプリが断定しない。**
> 設計時に「上限があるとされる」と書いていたが、**出典を確認したら無かった。**

## 2. 確認できたこと

### 合意分割制度

- 平成19年4月1日以後の離婚等が対象
- 婚姻期間中の厚生年金記録（標準報酬月額・標準賞与額）を分割する
- **当事者双方の合意または裁判手続により按分割合を定める**
  - 合意がまとまらない場合、一方の求めにより**裁判所が定めることができる**
- 請求期限：**原則、離婚等をした日の翌日から起算して5年以内**
  - （令和8年4月1日前に離婚等をした場合は別の扱いがある）

### ★ 公正証書が、添付書類として認められる

合意分割の請求手続きで、按分割合の合意を示す書類として次が挙げられている。

- **公正証書の謄本または抄本**
- 公証人の認証を受けた私署証書
- 年金分割の合意書（※ 双方が年金事務所に持参する必要がある）

> ★**このアプリが公正証書の原案を作る意義に、直接つながる。**
> 「年金分割の合意書」だけだと**双方そろって年金事務所に行く**必要がある。
> 公正証書にしておけば、それが要らない。

なお、電磁的記録の公正証書は**公証役場で出力し交付されたもの**に限る
（個人で印刷した電子データは無効）。

### 3号分割制度（別制度）

- 平成20年4月1日以後の第3号被保険者期間が対象
- **2分の1ずつ**と決まっている。**合意は不要**
- 第3号被保険者であった方からの請求で行う

> ★合意分割と3号分割は別物である。**アプリが扱うのは合意分割のほう。**
> 「2分の1」という数字は 3号分割の規定であって、
> 合意分割の上限としてそのまま引くと**誤りになる。**

### 効果の範囲

- 年金分割の効果は**厚生年金の報酬比例部分に限られる**
- **国民年金の老齢基礎年金等には影響しない**

> ★画面の「いま受け取っている額が動くわけではありません」は、この点と整合する。

## 4. 残す注記

画面（年金分割の入力）に、**恒久的な枠**として置いてある。外す前提のレイアウトにしない。

```
分ける割合を決められる範囲は、年金事務所が出す「情報通知書」で分かります。
お手続きの前に、年金事務所でご確認ください。

ご請求には期限があります（原則、離婚の翌日から5年以内）。
ここでの記録は、おふたりの合意を残すためのものです。
```
