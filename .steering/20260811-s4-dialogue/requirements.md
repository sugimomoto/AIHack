## 1. 目的

> **AIと1対1で話せる。感情がブロックされない。**

### 1.1 「感情がブロックされない」は機能要件である

一般的な対話AIは、罵倒や怒りを**拒否**する。

```
❌ 「そのような表現にはお答えできません」
     → 当事者は行き場を失う。そしてこのプロダクトは、
       まさにその感情を受け止めるために存在している。

✅ 受け止めて、相手には渡さない
     → 感情は本人の側に留まる。要求だけが構造化される。
```

**感情を出せる場所であることが、C1 の前提である。**
出せなければ、そもそも「相手に渡さない」という価値が発生しない。

### 1.2 このスライスの範囲

```
入力 →  意図分類【SMALL】 →  感情の受け止め【MEDIUM】 →  自分の画面に表示
                                                        ↑ ここまでが S4
        提案の構造化・事情の抽出・取次ぎ                    → S5
```

## 5. 設計上の要点

### 5.1 分類の失敗で止めない

意図分類は補助である。**失敗したら「分類なし」として受け止めに進む。**
分類できないことは、話を聞かない理由にならない。

### 5.2 受け止めは相手に渡らないことを前提に書ける

受け止めの応答は**本人しか読まない。**
したがって「相手を刺激しないか」を気にする必要がない。
**中立性の制約は取次ぎ（S5）にのみかかる。**

### 5.3 使ってはいけない語は出力側で検査する

プロンプトで指示するだけでは漏れる。**生成後に検査する。**
